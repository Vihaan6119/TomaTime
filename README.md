# Tomatime 

a tiny pomodoro timer. 25 minutes of focus, 5 minutes of break, and a red ring that drains while you work.

## features
- 25/5 focus-break cycles
- the ring drains with your time (red = focus, green = break)
- counts finished focus sessions per day (saved in localStorage)
- the tab title shows the time left, so you can watch it from your taskbar

## run it
1. clone or download
2. open `index.html`

that's it. no install, no account.
